# ربات پیشرفته فورواردر پیام‌رسان با گارد هوش مصنوعی (MTB Messenger Forwarder - Telegram & Bale)

**MTB Forwarder** یک سیستم سازمانی، پرسرعت و پایدار برای انتقال، پالایش و انتشار هوشمند پیام‌ها میان چندین کانال در پیام‌رسان‌های **تلگرام (Telegram)** و **بله (Bale)** است. فوروارد پیام‌ها تماماً بر بستر **Bot API رسمی** (بدون نیاز به ورود شماره تلفن، اکانت شخصی یا سشن) انجام می‌پذیرد و پلتفرم از طریق متغیر محیطی `PLATFORM` بین تلگرام و بله قابل سوییچ است. این ربات با مجهز بودن به یک **گارد هوش مصنوعی چندمرحله‌ای (AI Guard)**، پیام‌های دریافتی را تحلیل کرده و ضمن رعایت خطوط قرمز عقیدتی و سیاسی، **پیام‌های حاوی اخبار و نکات مفید را با ادبیاتی مؤدبانه و فاخر بازنویسی می‌کند**.

---

## 🌟 قابلیت‌های برجسته سیستم

- **🌐 پشتیبانی دوگانه از تلگرام و بله (Telegram & Bale Support):** اجرا بر روی تلگرام یا پیام‌رسان بله تنها با تغییر متغیر `PLATFORM=telegram` یا `PLATFORM=bale`.
- **🤖 معماری مبتنی بر ربات (Bot-Native Forwarding):** انتقال پیام‌ها بدون نیاز به اکانت شخصی، شماره تماس، کد SMS یا سشن؛ با امنیت کامل و مدیریت از طریق توکن ربات.
- **🔄 فوروارد زنده چند به چند (N→M Fan-Out):** دریافت خودکار پست‌ها از چندین کانال مبدأ و ارسال یا کپی به چندین کانال مقصد به صورت لحظه‌ای.
- **🛡 گارد هوش مصنوعی فارسی (Persian AI Guard):**
  - **پاسداری از مقدسات:** احترام قطعی به مقدسات اسلام، قرآن کریم، پیامبر (ص)، اهل‌بیت (ع) و مراسمات مذهبی.
  - **حریم نظام اسلامی و شهدا:** جلوگیری از توهین به اصل نظام، مقام معظم رهبری، شهدا و مسئولین نظام.
  - **مسدودسازی قاطع پروپاگاندا (`DROP`):** ممنوعیت مطلق تبلیغ و حمایت از رژیم پهلوی/سلطنت و رژیم صهیونیستی (اسرائیل).
  - **بازنویسی مؤدبانه و تلطیف لحن (`REWRITE`):** در صورت وجود خبر مفید اما لحن نامناسب، پیام حذف نمی‌شود بلکه با حفظ اصل خبر و با ادبیات رسمی و محترمانه بازنویسی می‌شود.
- **🎯 فیلتر موضوعی داینامیک (Topic Restriction):** امکان محدودسازی موضوعات مجاز کانال از داخل منوی ربات با تعیین نوع برخورد (حذف مستقیم یا صف بازبینی).
- **🗄 پایگاه داده دوگانه (Dual-Engine Database):**
  - **PostgreSQL 16 (با درایور مدرن Psycopg 3):** مجهز به استخر اتصال (Connection Pool) برای محیط‌های پروداکشن و کانال‌های پرحجم.
  - **SQLite (حالت WAL):** با تنظیمات پیشرفته `journal_mode=WAL` و `busy_timeout=30s` برای راه‌اندازی سریع و بدون دردسر محلی.
- **📱 مرکز فرماندهی و رابط کاربری مدرن:**
  - داشبورد تعاملی مجهز به به‌روزرسانی درجا (`In-place Refresh`).
  - ابزار اختصاصی **تست سلامت سیستم (`/health` یا `/status`)** با محاسبه پینگ Bot API (تلگرام یا بله)، دیتابیس و هوش مصنوعی.
  - فید فعالیت‌های اخیر با نام کانال‌ها، پیش‌نمایش خبر، زمان و برچسب اقدام.
  - صف بازبینی پیام‌های معلق مدیران (`/reviews`) با قابلیت‌های تأیید، ویرایش دستی و بازنویسی با یک کلیک.
- **⚡ همزمانی کنترل‌شده (Bounded Concurrency):** ظرفیت پردازش همزمان ۵ اسلات موازی جهت جلوگیری از فریز شدن سرور در ترافیک‌های سنگین.

## 🚀 راه‌اندازی سریع در ۵ دقیقه

### ۱. پیش‌نیازها
- پایتون نسخه 3.12 یا بالاتر
- توکن ربات از [@BotFather](https://t.me/BotFather) (در تلگرام) یا [@Bot_Father](https://ble.ir/bot_father) (در پیام‌رسان بله)

### ۲. نصب وابستگی‌ها
```powershell
# کلون پروژه و ساخت محیط مجازی
git clone https://github.com/your-username/telegram-forwarder.git
cd telegram-forwarder
python -m venv .venv
.\.venv\Scripts\activate

# نصب پکیج‌های پایتون
pip install -r requirements.txt
```

### ۳. پیکربندی فایل `.env`
از روی فایل نمونه یک کپی بسازید:
```powershell
cp .env.example .env
```
اطلاعات ضروری زیر را در `.env` وارد کنید:
```dotenv
# انتخاب پلتفرم: telegram یا bale
PLATFORM=telegram

# توکن ربات دریافتی از BotFather (در تلگرام یا بله)
BOT_TOKEN=توکن_ربات_شما
ADMIN_IDS=شناسه_عددی_اکانت_شما

# تنظیم دیتابیس (SQLite پیش‌فرض یا PostgreSQL)
DATABASE_URL=sqlite:///data/forwarder.db

# تنظیمات هوش مصنوعی (OpenRouter / Gemini / OpenAI)
AI_ENABLED=true
AI_API_KEY=کلید_api_شما
AI_MODEL=google/gemini-2.5-flash
AI_BASE_URL=https://openrouter.ai/api/v1
```

### ۴. اجرای ربات
```powershell
python main.py
```
پس از اجرای ربات، ربات بلافاصله آماده به کار است. کافی است ربات را در کانال‌های مبدأ و مقصد به عنوان ادمین اضافه کنید، سپس در پی‌وی ربات دستور `/start` را بزنید و کانال‌ها را تنظیم نمایید.
