# فهرست راهنما و مستندات پروژه MTB Telegram Forwarder

به مرکز مستندات رسمی ربات **MTB Telegram Forwarder** خوش آمدید. این مجموعه مستندات به زبان فارسی روان، ساده و ساختاریافته تدوین شده است تا هم مدیران و ادمین‌های کانال‌ها و هم توسعه‌دهندگان پایتون بتوانند به سادگی از تمامی امکانات سیستم بهره‌برداری کنند.

## 🧭 مسیر پیشنهادی مطالعه بر اساس نیاز شما

### ۱. اگر می‌خواهید ربات را برای اولین بار راه بیندازید:
1. ابتدا [README.md](../README.md) را برای راه‌اندازی محلی یا [railway.md](railway.md) را برای راه‌اندازی روی سرور بخوانید.
2. سپس [database.md](database.md) را برای انتخاب بین SQLite و PostgreSQL مطالعه فرمایید.
3. در نهایت [telegram-ui.md](telegram-ui.md) را جهت تنظیم کانال‌های مبدأ و مقصد و شروع انتقال مشاهده کنید.

### ۲. اگر می‌خواهید نحوه سانسور، بازنویسی و قوانین محتوایی را سفارشی کنید:
1. سند [guard.md](guard.md) را جهت درک نحوه کارکرد گارد بخوانید.
2. سند [guard-settings.md](guard-settings.md) را برای یادگیری تنظیم حساسیت‌ها از تلگرام یا فایل JSON بررسی کنید.
3. با استفاده از [guard-customization-guide.md](guard-customization-guide.md) پرامپت و سیاست دلخواه خود را تولید کنید.

### ۳. اگر در کارکرد ربات، اتصال تلگرام یا ارسال پیام به مشکل برخورده‌اید:
1. دستور `/health` را در ربات تلگرام اجرا کنید تا وضعیت زنده قطعات را ببینید (توضیحات در [telegram-ui.md](telegram-ui.md)).
2. سند [logging.md](logging.md) را برای تحلیل پیام‌های خطا مطالعه فرمایید.
