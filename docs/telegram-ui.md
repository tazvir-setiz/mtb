# رابط تلگرام

داشبورد فارسی وضعیت مبدأ، مقصد، پردازش هوشمند، امضا و انتقال خودکار را نشان می‌دهد.
کانال انتخاب‌شده فقط پس از تأیید ذخیره می‌شود؛ لغو انتخاب، کانال قبلی را نگه می‌دارد.
بخش «انتقال خودکار» برای کنترل پیام‌های آینده و بخش «انتقال پیام‌ها» برای پیام‌های قبلی است.

## امکانات API

رابط از دکمه‌های رنگی و کپی شناسه، و قابلیت‌های مرتبط Bot API 10.3 استفاده می‌کند:

- `InlineKeyboardButton.disabled`: دکمهٔ انتقال تا تنظیم کانال‌ها غیرفعال است.
- `InlineKeyboardMarkup.force_reply`: هنگام درخواست شناسه یا کانال، ورودی پاسخ همراه دکمهٔ لغو نمایش داده می‌شود.

فیلدهای جدید از طریق `api_kwargs` عمومی python-telegram-bot ارسال می‌شوند.
`disabled` یک نوع مستقل دکمه با مقدار `{}` است و callback ندارد.
`force_reply` فقط روی پیام ورودی جدید تنظیم می‌شود؛ مقدار آن هنگام ویرایش تغییر نمی‌کند.
نمایش امکانات جدید به نسخهٔ کلاینت تلگرام هم وابسته است.
این تغییر، پشتیبانی عمومی از تمام امکانات API مانند Rich Messages یا پرداخت را اضافه نمی‌کند.

منابع رسمی بررسی‌شده در ۲۵ سپتامبر ۲۰۲۶:

- https://core.telegram.org/bots/api-changelog
- https://core.telegram.org/bots/api#inlinekeyboardmarkup
- https://core.telegram.org/bots/api#inlinekeyboardbutton

## بررسی پس از استقرار

پس از deploy، `/menu` را باز کنید؛ تنظیم مبدأ و مقصد را تا تأیید ادامه دهید،
انتقال یک پیام آزمایشی را بررسی کنید و سپس انتقال خودکار را روشن و خاموش کنید.
تست‌های محلی payload و مسیرهای رابط را بدون ارسال واقعی به تلگرام بررسی می‌کنند.
